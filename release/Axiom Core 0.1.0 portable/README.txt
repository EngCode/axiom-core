Axiom Core 0.1.0 - portable test build

1. Double-click "Start Axiom Core.cmd".
2. Your workspace is created in the "data" folder next to this file.
3. WebView2 profile is created in "webview-data".
4. The first run copies seed\axiom.db, so projects, tasks and docs are already there.

This build is unsigned. If Windows SmartScreen warns, choose More info -> Run anyway.
To move the app, move the whole folder. To back up, copy the "data" folder.
